# 為什麼我選擇 SiYuan(思源筆記)？一個工程師打造個人知識庫的使用經驗

SiYuan(思源筆記) 官網: https://b3log.org/siyuan/

SiYuan(思源筆記) GitHub: https://github.com/siyuan-note/siyuan

---

做了二十年的軟體開發之後，我慢慢發現一件事情：

**工程師真正重要的資產，可能不是寫過多少程式，而是這些年累積下來的知識。**

從早期的軟體開發，到後來接觸資料庫、網路、資訊系統，再到 PLC、CNC、工業相機、機械手臂、AGV、自動化系統，甚至開始帶團隊、做專案管理，我需要處理的知識範圍變得愈來愈廣。

問題也跟著出現：

**這麼多東西，到底要放在哪裡？**

更重要的是：

**五年、十年以後，我還找得到嗎？**

這也是我後來開始使用 SiYuan（思源筆記）的原因。

---

## 從「記筆記」到「管理自己的知識」

以前我對筆記軟體的要求其實很簡單。

能夠建立資料夾、寫文字、貼圖片、搜尋，就已經差不多了。

但隨著累積的資料愈來愈多，我開始發現真正的問題不是「有沒有把東西記下來」，而是：

> **記下來之後，這些知識還能不能被重新找到、重新組合、重新利用？**

例如「工業相機」看起來是一個主題，但實際工作時，它可能同時涉及：

- 鏡頭焦距
- Sensor Size
- FOV
- 景深
- 光源
- 曝光
- 影像處理
- PLC 通訊
- 機械手臂定位
- 自動化設備整合

如果全部只是存在不同資料夾裡的一篇篇文件，時間久了，很容易變成一座「文件倉庫」。

資料很多，但真正需要的時候還是找不到。

所以我後來對筆記軟體的要求開始改變。

我需要的已經不是單純的 Notebook。

而是一套：

**Personal Knowledge Management System（個人知識管理系統）。**

---

## 為什麼後來選擇 SiYuan？

SiYuan 最吸引我的地方，第一個其實不是介面，也不是 Markdown。

而是：

**資料是自己的。**

這件事情對我非常重要。

我希望自己累積十年、二十年的技術資料，不要完全依賴某一家公司的雲端服務。

因為任何線上服務都有可能改變。

服務可能漲價、功能可能調整、免費方案可能取消，甚至產品本身有一天可能不存在。

但我的知識不應該跟著消失。

SiYuan 採用 Local-first 的設計思維，資料主要掌握在自己的 Workspace 中。

這讓我比較放心。

因為即使未來有一天我不再使用 SiYuan，我仍然希望可以把自己的內容帶走，而不是被某一套軟體綁住。

---

# 真正讓我覺得 SiYuan 有意思的，是 Block

使用 SiYuan 一段時間後，我認為它跟傳統筆記最大的差異之一，是 ​**Block（內容塊）** 。

以前我們習慣把「文件」當成最小單位。

例如：

```text
工業相機/
    鏡頭
    景深
    光源
    相機選型
```

但實際上，我真正想重複利用的往往不是整篇文件，而是其中某一小段知識。

例如：

> 景深與光圈、焦距、工作距離及允許模糊程度有關。

這一段內容可能同時會出現在：

- 工業相機基礎
- 鏡頭選型
- AOI 設計
- Robot Vision
- 某個實際專案

傳統做法通常是 Copy & Paste。

但問題是：

**複製五次之後，到底哪一份才是最新的？**

SiYuan 的 Block Reference 改變了這件事情。

我可以把原本的內容當成一個知識來源，其他地方只是引用它。

這個概念對做軟體的人其實非常自然。

某種程度上很像：

```text
不要 Copy & Paste Code
而是抽成 Function / Module
```

知識其實也可以這樣管理。

**不要 Copy & Paste Knowledge，而是 Reference Knowledge。**

這是我非常喜歡 SiYuan 的地方。

---

# 知識不是一棵樹，而是一張網

以前整理資料時，我很容易陷入另一個問題：

> 「這篇到底要放在哪個資料夾？」

例如 AGV 的 LiDAR 資料到底應該放在：

```text
AGV/
```

還是：

```text
Sensor/
```

還是：

```text
SLAM/
```

後來我慢慢覺得，這個問題本身可能就問錯了。

因為真實世界的知識，本來就不完全是樹狀結構。

它比較像：

```text
AGV
 │
 ├── LiDAR
 │      │
 │      └── SLAM
 │             │
 │             └── Path Planning
 │
 └── PLC
        │
        └── Factory Automation
```

甚至這張關係圖還會繼續往外延伸。

所以我現在比較喜歡：

**資料夾負責大方向分類，連結與引用負責知識之間的關係。**

SiYuan 的 Block Reference、Backlink、Tag 等功能，剛好很適合這種使用方式。

這讓筆記開始從「文件管理」慢慢變成「知識管理」。

---

# 我仍然很重視 Markdown

另外一個我喜歡 SiYuan 的原因，是 Markdown。

身為長期使用電腦與程式開發工具的人，我不希望自己的資料被鎖在某種很特殊、只有特定軟體才能理解的格式裡。

Markdown 最大的優點就是簡單、容易交換。

即使未來更換其他工具，我仍然希望自己的內容可以被閱讀、被轉移、被重新利用。

但另一方面，我也不希望每天寫筆記時，滿畫面都是 Markdown 符號。

SiYuan 在這方面取得了一個我很喜歡的平衡：

**平常是所見即所得的編輯體驗，需要交換資料時又可以回到 Markdown。**

所以寫筆記的時候，我可以專心思考內容。

需要把資料拿去做其他用途時，又保留很大的彈性。

---

# 對工程師來說，我很重視「可以自動化」

這也是我認為 SiYuan 很有潛力的地方。

因為它不只是提供一個編輯器。

它還提供 API、SQL Query 等能力，也留下很多可以自行延伸的空間。

對一般使用者而言，這些功能可能不是必要的。

但對工程師來說，我認為這是一個非常大的優點。

因為我的知識庫未來不一定只能靠「手」操作。

例如可以想像：

```text
工作與研究資料
       ↓
     SiYuan
       ↓
      AI
       ↓
摘要 / 分類 / 關聯
       ↓
重新整理與搜尋
```

甚至未來我希望 AI 可以協助回答：

> 我以前研究過這個問題嗎？

> 兩年前那個 PLC 專案最後是怎麼解決的？

> 我所有關於工業相機景深的研究有哪些？

> 幫我整理過去所有關於 AGV 的研究。

到了這個階段，SiYuan 對我來說就不再只是一套筆記軟體。

它開始有可能成為：

**我的 Personal Knowledge Database。**

而 AI 則有機會成為這個資料庫上面的智慧操作介面。

這也是我目前很想繼續發展的方向。

---

# 當了主管之後，我反而更需要自己的知識庫

這幾年還有一個很大的變化。

以前當工程師時，大部分時間可以專心研究一個問題。

現在需要同時處理軟體、自動化、網路、資訊系統、人員、專案、招募、跨部門協調等很多不同的事情。

一天可能上午還在討論 PLC，下午變成 NAS Backup，接著討論人員安排，晚上又研究 AI。

最大的問題不是學不會。

而是：

**大腦沒有辦法同時記住這麼多 Context。**

所以我愈來愈不把筆記系統當成「記事本」。

我把它當成：

**外部記憶體。**

大腦負責：

**思考、判斷、創造。**

SiYuan 負責：

**記住。**

搜尋系統負責：

**找回來。**

AI 未來負責：

**重新理解與組合。**

這可能才是我現在使用 SiYuan 最重要的原因。

---

# SiYuan 並不是完美的筆記軟體

當然，我不認為 SiYuan 適合所有人。

如果只是想記：

- 今天要買什麼
- 明天要做什麼
- 幾行臨時文字

那麼很多更簡單的筆記 App 都可以完成，而且可能還更方便。

SiYuan 真正的價值，需要在資料累積之後才會慢慢出現。

當你的筆記從：

```text
100 篇
```

變成：

```text
1,000 篇
```

甚至未來：

```text
10,000 篇
```

問題就不再是：

 **「哪一套軟體寫字比較漂亮？」**

而是：

 **「十年前寫過的東西，我今天還能不能找到並重新利用？」**

這是我現在選擇知識管理工具時最重視的事情。

---

# 我希望十年後，它仍然是我的知識

我現在對 SiYuan 的期待其實很簡單。

我不只是想找一套「好用的筆記軟體」。

我想建立的是一個可以陪自己很多年的：

**Personal Knowledge Base。**

工作遇到的問題放進去。

研究過的技術放進去。

失敗的經驗放進去。

解決問題的方法放進去。

管理團隊得到的經驗也放進去。

然後透過 Block、Link、Tag、Database、搜尋以及未來的 AI，讓這些原本散落的經驗慢慢產生關係。

如果十年後回頭看，我希望看到的不是：

 **「我寫了幾千篇筆記。」**

而是：

 **「這二十年、三十年的工作、研究與思考，逐漸形成了一套真正屬於自己的知識體系。」**

而這也是我目前使用 SiYuan 最大的理由。

**我不是在找一套可以取代紙本筆記的軟體。**

**我是在建立自己的第二大腦。**
