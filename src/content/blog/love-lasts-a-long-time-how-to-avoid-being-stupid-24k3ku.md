# Ai用久!人不變笨的方法!

- RHFan: 現在AI太方便了，導致以下現象及問題:

  - 跟AI互動學到的重要知識都懶惰不存入筆記了(因為問Ai比查資料更快得到答案)。
  - 對於這些知識的印象變模糊(沒有深入思考, 深入記憶)。
  - 自己的專業能力變弱，只能依賴AI。
  - 失去審核判斷力，把事情做對及及做對的事情的能力變弱。
  - (因為大腦神經元連結的特性是<span data-type="text" style="background-color: var(--b3-card-warning-background); color: var(--b3-card-warning-color);">用進廢退</span>)

‍

- 以前:

  - 遇到問題 → 查資料
  - 查資料 → 思考
  - 思考 → 整理成筆記
  - 筆記 → 形成自己的知識體系
- 現在:

  - 遇到問題 → 問 AI
  - AI 直接給答案
  - 問題解決
  - 結束
- 中間少了兩個環節:

  - <span data-type="text" style="background-color: var(--b3-card-warning-background); color: var(--b3-card-warning-color);">01.</span>**主動思考**
  - <span data-type="text" style="background-color: var(--b3-card-warning-background); color: var(--b3-card-warning-color);">02.</span>**知識整理**
- 結果:

  - **01.思考能力變弱**
  - **02.專業能力退化**
  - **導致→失去審核判斷力。**
- 未來最危險的人?

  - **什麼都問 AI，但什麼都不整理的人。**

- 未來最強的人?

  - **能把AI當成外接大腦，同時又持續訓練自己內在大腦的人。(這種人才能在Ai時代比其他高手強)**
- 怎麼做？

  - 查資料 → 思考

    - **查完資料要思考判斷，挑戰Ai給的答案。**
  - 思考 → 整理成筆記

    - **存自己消化過, 自己寫出來的東西,** <span data-type="text" style="background-color: var(--b3-card-warning-background); color: var(--b3-card-warning-color);"> </span> **(例如: 經驗, 判斷, 架構)**
    - **在筆記最後附上Ai的互動記錄url，日後參考用。**
    - (不是自己寫出來的東西, 問Ai就直接得答案)
  - 刻意用一些工具訓練大腦

    - **讀書**
    - **下圍棋**
